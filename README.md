# 🌈 Rainbow Text Highlighter

> 8 色彩虹高亮网页文字 · Chrome / Edge 浏览器扩展（Manifest V3）
> 8-color rainbow text highlighter for Chrome & Edge (Manifest V3)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Manifest V3](https://img.shields.io/badge/Manifest-V3-orange)
![Platform](https://img.shields.io/badge/Platform-Chrome%20%26%20Edge-brightgreen)

选中网页文字，立即弹出工具条：**8 个颜色按钮 + 一个文本框**。每个颜色按钮对应一个文本框——点红色按钮，输入的词就用红色高亮；点蓝色按钮，输入的词就用蓝色高亮。**每个颜色各管各的词**，刷新页面后高亮自动恢复。

## ✨ 功能特性

- **8 色高亮背景**：红 `#ff6b6b`、橙 `#ffa94d`、黄 `#ffd43b`、绿 `#69db7c`、青 `#3bc9db`、蓝 `#4dabf7`、靛 `#748ffc`、紫 `#b197fc`（彩虹顺序，红色固定第一位）
- **每个颜色一个文本框**：点颜色按钮切换颜色，在文本框输入该颜色的高亮词（空格分隔），全页所有出现位置立即高亮
- **多色同时高亮**：想要几个颜色就点几个按钮分别填词，互不影响
- **选中即上色**：选中文字 → 点颜色按钮，立刻给这段文字垫上该颜色背景
- **💾 刷新后自动恢复**：高亮按网址保存在浏览器本地存储，刷新页面、重新打开网页都会自动重新应用；网页动态加载的新内容也会自动补上高亮
- **气泡效果**：高亮是圆角背景块，垫在原文文字后面，不影响网页原有样式
- **无快捷键**：全部操作靠鼠标和文本框，简单直观；Esc 收起工具条
- **可定制**：扩展弹窗里可修改任意颜色、单独开关某个颜色、一键恢复默认

## 📦 安装（开发者模式加载）

> 本扩展尚未上架 Chrome 应用商店，需以"加载已解压的扩展程序"方式安装。

### Chrome

1. 下载本仓库代码（`Code → Download ZIP`，或 `git clone`）
2. Chrome 地址栏输入 `chrome://extensions` 回车
3. 打开右上角 **"开发者模式"** 开关
4. 点击 **"加载已解压的扩展程序"**，选择仓库根目录（含 `manifest.json`）
5. 完成！打开任意普通网页测试

### Edge

同上，改为 `edge://extensions` → "开发人员模式" → "加载解压缩的扩展"。

> ⚠️ 装完没反应？扩展只对**之后打开/刷新**的网页生效：安装后请刷新已打开的标签页（F5）。
> 浏览器内置页面（`chrome://`、Chrome 应用商店、新标签页、PDF 预览等）**不支持**注入；给本地 `file://` 网页用需在扩展详情页打开"允许访问文件网址"。
>
> ⚠️ 报 "Extension context invalidated"？这是点了"重新加载"后，还开着的旧页面里残留旧脚本导致的：重新加载扩展后**把已打开的网页刷新一遍**即可；新版本已内置防护，残留脚本不会再刷报错。
>
> ⚠️ "在页面上打开关键词框"没反应？v1.4.1 起已内置自愈：弹窗会自动尝试重新注入脚本，仍失败时会在弹窗里提示原因并提供"刷新此页"按钮；右键菜单则自动刷新后重开关键词框。

## 🎯 使用说明

| 操作 | 效果 |
| --- | --- |
| 选中文字 → 工具条出现 | 8 个颜色按钮 + 当前颜色标签 + 长方形文本框 |
| 点颜色按钮（如 蓝） | 切换"当前颜色"，文本框显示并编辑该颜色的词 |
| 在文本框输入词汇（空格分隔） | 全页用当前颜色高亮所有出现位置，实时更新 |
| 分别点不同颜色按钮填词 | 每个颜色各管各的词，全部同时高亮 |
| 点击颜色按钮（有选中文字时） | 顺便给选中文字上该颜色 |
| 清空文本框 | 移除当前颜色的关键词高亮 |
| 回车 / Esc | 收起工具条（高亮保留） |
| 点扩展图标 → "🔍 在页面上打开关键词框" | 不选文字也能打开工具条，直接填词 |
| 右键 → "按关键词高亮" | 同上，直接弹出关键词框 |
| 选中 → 右键 → 🌈 彩虹高亮 | 给选中的文字上色 / 移除选中高亮 |
| 工具条"移除选中" / "全部清除" | 移除选中区域高亮 / 移除本页所有高亮 |

### 提示

- 中文按**子串**匹配，英文/数字按**整词**匹配（`cat` 不会误亮 `category`）
- 高亮按网址保存，最多保留最近 **50 个页面**（超出自动清理最旧的）
- 颜色设置同步保存在浏览器账号中，换设备登录同一账号自动同步

## 🛠️ 技术说明

- **Manifest V3**，Chrome / Edge（Chromium 内核）通用
- 高亮通过包裹文本节点的 `<mark>` 元素实现，不修改网页文件
- 持久化：`chrome.storage.local` 按 URL 保存关键词与颜色；`MutationObserver` 自动为动态加载内容补亮
- 无任何外部依赖、无广告、不联网上传数据
