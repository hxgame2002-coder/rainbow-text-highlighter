# 🌈 彩虹高亮助手（Google Chrome 扩展）

给网页文字快速添加彩色"气泡"背景高亮：选中文字弹出工具条，右侧**长方形文本框**里输入词汇（空格分隔），每个词自动按彩虹顺序分配不同颜色，全页所有出现位置立刻被垫上背景色。红橙黄绿青蓝靛紫按彩虹顺序排列，红色固定为第一位。

## ✨ 功能特性

- **8 色高亮背景**：红 `#ff6b6b`、橙 `#ffa94d`、黄 `#ffd43b`、绿 `#69db7c`、青 `#3bc9db`、蓝 `#4dabf7`、靛 `#748ffc`、紫 `#b197fc`
- **关键词批量高亮（核心功能）**：选中任意文字 → 工具条弹出 → 点一个**颜色按钮**（红/橙/…/紫）→ 在**长方形文本框**输入该颜色的高亮词，多个词用**空格分隔**，全页所有出现位置立即用这个颜色高亮
  - **每个颜色各管各的词**：点红色按钮输入"苹果"，点蓝色按钮输入"天空"，互不影响，想要几个颜色就点几个按钮分别填词
  - 支持中文、英文、数字；英文按整词匹配（不会误伤 `cat` 之于 `category`），中文按子串匹配
  - 修改文字实时更新高亮；清空文本框移除该颜色的关键词
- **选中即上色**：选中文字 → 点颜色按钮，立刻给这段文字垫上该颜色背景（工具条保留，可继续输入关键词）
- **无需先选中**：点扩展图标 → 弹窗里点"🔍 在页面上打开关键词框"，或右键 → "按关键词高亮"，工具条直接出现在页面右上角，输入即可
- **气泡效果**：高亮是圆角背景块，垫在原文文字后面，不影响网页原有文字样式
- **💾 刷新后自动恢复**：高亮保存在浏览器本地存储中（按网址保存），刷新页面、重新打开网页都会自动重新应用；网页后续动态加载的内容也会自动补上高亮
- **无快捷键**：全部操作靠鼠标和文本框，简单直观；Esc 可收起工具条
- **可定制**：弹窗里可改任意颜色、单独开关某个颜色、一键恢复默认

## 📦 安装步骤（Chrome）

1. 下载/复制本文件夹到本地（例如 `chrome-highlighter`）
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
3. 打开右上角 **"开发者模式"** 开关
4. 点击 **"加载已解压的扩展程序"**
5. 选择本文件夹（含 `manifest.json` 的那个目录）
6. 完成！随便打开一个普通网页测试

> ⚠️ **装完没反应？** 扩展只对**之后打开/刷新**的网页生效：
> - 安装后请**刷新**已打开的标签页（F5 或 Ctrl+R）
> - 浏览器内置页面（`chrome://`、Chrome 应用商店、新标签页等）**不支持**注入
> - Chrome 自带的 PDF 预览页也**不支持**；如要给本地 `file://` 网页用，需在扩展详情页打开"允许访问文件网址"
>
> ⚠️ **报 "Extension context invalidated"？** 这是点了"重新加载"后，还开着的旧页面里残留旧脚本导致的：
> 重新加载扩展后**把已打开的网页刷新一遍**即可；新版本已内置防护，残留脚本不会再刷报错。
>
> ⚠️ **"在页面上打开关键词框"没反应？** v1.4.1 起已内置自愈：弹窗会自动尝试重新注入脚本，
> 仍失败时会在弹窗里提示原因并提供"刷新此页"按钮；右键菜单则自动刷新后重开关键词框。

## 🎯 使用说明

| 操作 | 效果 |
| --- | --- |
| 选中文字 → 工具条出现 | 8 个颜色按钮（红/橙/…/紫）+ 当前颜色标签 + 长方形文本框 |
| 点颜色按钮（如 蓝） | 切换"当前颜色"，文本框显示并编辑该颜色的词 |
| 在文本框输入词汇（空格分隔） | 全页用当前颜色高亮所有出现位置，实时更新 |
| 分别点不同颜色按钮填词 | 每个颜色各管各的词，全部同时高亮 |
| 点击颜色按钮（有选中文字时） | 顺便给选中文字上该颜色 |
| 清空文本框 | 移除当前颜色的关键词高亮 |
| 回车 | 收起工具条（高亮保留） |
| Esc | 收起工具条 |
| 点扩展图标 → "🔍 在页面上打开关键词框" | 不选文字也能打开工具条，直接填词 |
| 右键 → "按关键词高亮" | 同上，直接弹出关键词框 |
| 选中 → 右键 → 🌈 彩虹高亮 | 给选中的文字上色 / 移除选中高亮 |
| 工具条上"移除选中" / "全部清除" | 移除选中区域高亮 / 移除本页所有高亮 |

## ⚠️ 说明与限制

- 高亮**保存**在浏览器本地存储（`chrome.storage.local`），**刷新页面后自动恢复**；不会改动网页文件
- 保存按网址区分，最多保留最近 **50 个页面**，超出自动清理最旧的；v1.4.2 起每页独立存储，多标签页互不干扰，**关掉浏览器重开后自动恢复**（多次重试 + 首次交互兜底）
- "选中上色"的高亮恢复时，会把**同样文字的所有出现位置**都高亮（关键词类高亮本来就是这样）；个别手选的句子若在文中出现多次，恢复后可能比原来多一点
- 无法在 `chrome://`、Chrome 应用商店、PDF 预览等浏览器内置页面使用
- 颜色设置保存在浏览器同步存储中，换设备登录同一账号会自动同步

## 📁 文件结构

```
chrome-highlighter/
├── manifest.json     # 扩展清单（Manifest V3）
├── content.js        # 核心逻辑：工具条、多词多色关键词高亮、选区内上色
├── content.css       # 气泡高亮与工具条样式
├── background.js     # 后台：右键菜单
├── popup.html        # 扩展弹窗
├── popup.css
├── popup.js          # 弹窗逻辑：开关、改色、打开关键词框、清除
└── icons/            # 扩展图标（16/48/128）
```

> 本扩展基于 Manifest V3，同样适用于 Microsoft Edge（在 `edge://extensions` 用"加载解压缩的扩展"加载即可）。
